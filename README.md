## Data Science Portfolio

A collection of projects exploring how data can inform decisions in healthcare, public safety, and operations. The work emphasizes practical questions, reproducible methods, and clear communication of findings.

### Tools and Methods

- **Python:** Data cleaning, analysis, visualization, API integration, and automation.
- **R:** Data transformation, statistical exploration, and geographic visualization.
- **SQL and SQLite:** Querying, aggregation, and structured data management.
- **Geospatial Analysis:** Interactive mapping and exploration of location-based patterns.
- **AI-Assisted Development:** Support for coding and analytical workflows, with review and validation of outputs.

### Approach

Projects follow a structured process: define the question, assess data quality, prepare and analyze the data, and communicate results. Each analysis considers assumptions, limitations, and the practical relevance of its findings.
